DayByDay is a desktop planner that splits your day into **blocks** — named
stretches of time like "Morning" or "Deep Work" — and shows you only the tasks
that belong to the block you're in right now.

## The main screens

| Screen | What it's for |
|---|---|
| **Home** | A clock and the tasks for the current block |
| **Tasks** | Every task, grouped and filterable |
| **Calendar** | Your tasks and imported calendar events on a timeline |
| **Blocks** | Define the time blocks that make up your day |
| **Pomodoro** | A focus timer |

Jump between them from the sidebar or the **Go** menu.

## Your first five minutes

1. Open **Calendar → Blocks** and set up a few blocks that match your day.
2. Press <kbd>⌘</kbd> <kbd>N</kbd> to [add a task](/app/addtask/) and assign it to a block.
3. Go back to **Home** — the task shows up while its block is active.
