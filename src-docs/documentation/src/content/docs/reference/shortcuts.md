---
title: Keyboard Shortcuts
description: Every keyboard shortcut in DayByDay
---

| Shortcut | Action |
|---|---|
| <kbd>⌘</kbd> <kbd>N</kbd> | Create task |
| <kbd>⌥</kbd> <kbd>R</kbd> | Open the Cognition Bar (works from any app) |
| <kbd>⌘</kbd> <kbd>,</kbd> | Settings |
| <kbd>⌘</kbd> <kbd>\\</kbd> | Toggle sidebar |
| <kbd>⌘</kbd> <kbd>1</kbd> | Toggle left panel |
| <kbd>⌘</kbd> <kbd>2</kbd> | Toggle right panel |
| <kbd>⌘</kbd> <kbd>=</kbd> | Zoom in |
| <kbd>⌘</kbd> <kbd>-</kbd> | Zoom out |
| <kbd>⌘</kbd> <kbd>0</kbd> | Actual size |
