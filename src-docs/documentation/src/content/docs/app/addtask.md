---
title: Add Task
description: The different ways to add a task
---

There are a few ways to add a task, depending on where you are.

## From the menu

Press <kbd>⌘</kbd> <kbd>N</kbd>, or choose **Tasks → Create Task** from the menu
bar. The task creator opens on top of whatever screen you're on.

## From anywhere with the Cognition Bar

Press <kbd>⌥</kbd> <kbd>R</kbd> to open the Cognition Bar. This shortcut is
global, so it works even when DayByDay isn't the frontmost app — handy for
catching a thought without switching windows.

## From a calendar

Connect a calendar or import an `.ics` file and its events appear as tasks.
Imported events are read-only and can't be dragged.

:::tip
Give a task a **block** so it shows up on the Home screen at the right time of day.
:::
